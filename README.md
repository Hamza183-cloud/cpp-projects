# Hello World - C++ Program

## Overview
A simple C++ program that demonstrates basic console output using the standard library.

## Description
This is a beginner-level C++ program that prints a greeting message to the console. It serves as an introduction to C++ syntax and the standard output stream.

## Output
```
Hello, AI Course!
```

## Compilation and Execution

### Compile
```bash
g++ hello_world.cpp -o hello_world
```

### Run
```bash
./hello_world
```

Or on Windows:
```bash
hello_world.exe
```

## Code Explanation
- `#include <iostream>` - Includes the input/output stream library
- `using namespace std;` - Uses the standard namespace
- `cout << "..." << endl;` - Outputs text to console and adds a newline
- `return 0;` - Indicates successful program execution

## Requirements
- C++ compiler (g++, clang, or MSVC)

## Topics Covered
- Basic C++ syntax
- Standard input/output (iostream)
- Main function
- String literals
- Console output
